# 💅 Nipunika Salon 💇‍♀️💆‍♀️

A modern, responsive website for Nipunika Salon, a premium beauty and wellness service provider in Sri Lanka. 🇱🇰

## 📜 Description

Nipunika Salon website is a professional, visually appealing frontend solution designed to showcase the salon's services 💄, highlight their expert team 🧑‍🎨, display their work portfolio 🖼️, and provide an online booking system for clients 📅. The website aims to create a luxurious online presence that matches the premium services offered by the salon. ✨

## 🛠️ Technologies Used

  - HTML5 🌐
  - CSS3 (Tailwind CSS) 🎨
  - JavaScript ⚙️
  - Three.js (for background effects) ✨
  - Font Awesome (for icons) \<i\>\</i\>
  - Google Fonts 🖋️
  - Swiper.js (for testimonial carousel) 🎠
  - AOS - Animate On Scroll (for scroll animations) 🪄

## ⭐ Features

  - **Responsive Design**: Fully responsive layout that works on all devices 📱💻🖥️
  - **Dark/Light Mode**: Theme toggle functionality ☀️🌙
  - **Service Showcasing**: Detailed presentation of all beauty services and packages 💅💇‍♀️💆‍♂️
  - **Team Presentation**: Section highlighting the salon's expert staff 🌟
  - **Portfolio Gallery**: Filterable gallery of work samples and transformations 📸
  - **Testimonials**: Client reviews displayed in a carousel 🗣️💬
  - **Online Booking System**: Form for clients to schedule appointments 🗓️✍️
  - **Contact Information**: Multiple ways for clients to get in touch 📞📧📍
  - **Interactive Elements**: Animations, hover effects, and visual feedback 互动💫
  - **Newsletter Signup**: Form for marketing subscription 💌

## 🚀 Installation

1.  Clone the repository:
    ```
    git clone https://github.com/yourusername/NipunikaSalon.git 📁
    ```
2.  Open the project folder:
    ```
    cd NipunikaSalon 📂
    ```
3.  Open `index.html` in your browser to view the website. 🌐

## 💻 Usage

The website can be deployed to any web hosting service. ☁️ No server-side processing is required as it's a static website. For local development, you can use a local server like Live Server in VSCode. 🛠️

## 📁 Project Structure

  - `index.html` - Main HTML file containing the entire website 📄
  - `assets/` - Directory containing:
      - `images/` - All website images including logo, gallery items, etc. 🖼️
      - `js/` - JavaScript files including main.js with custom scripts 📜
      - `css/` - Any additional CSS files (main styling is done with Tailwind) 🎨

## 🎨 Customization

1.  Replace the placeholder images with actual salon images 📸
2.  Update the contact information, working hours, and location 📞⏰📍
3.  Modify the services and packages to match the salon's offerings 💅✨
4.  Add actual team member photos and information 🧑‍🤝‍🧑
5.  Update the WhatsApp link with the salon's actual number 📱💬
